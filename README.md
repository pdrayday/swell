# Swell

Launch site for **Swell** ready-to-drink protein shakes (Cookies & Cream, Cake Batter, Chocolate, Vanilla) and protein smoothies (Pina Colada, Mango, Berry Bliss). Tap or swipe between the two lines.

Live: https://pdrayday.github.io/swell/

## Files
- `index.html`: the whole site (single page, no build step)
- `img/`: bottles, 12-packs and flavor art (WebP)
- `robots.txt`, `sitemap.xml`: search engine and AI crawler setup
- `llms.txt`: plain-language fact sheet for AI answer engines

## Moving to a custom domain
Replace `https://pdrayday.github.io/swell` in `index.html`, `robots.txt`, `sitemap.xml` and `llms.txt` with the new domain, then add a `CNAME` file.
